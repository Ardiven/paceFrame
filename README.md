# PaceFrame AI — Adaptive Running Coach

Platform pelatihan lari adaptif berbasis sport science, Multimodal Vision AI, dan penyesuaian jadwal yang dikendalikan Safety Engine deterministik (Target 5K Sub-30 hingga Sub-25).

## Tech Stack
- **Frontend**: React (Vite + JavaScript / JSX + Tailwind CSS + Recharts)
- **Backend**: Node.js + Express.js (JavaScript / ES Modules) + Multer + Zod
- **Database & Auth**: PostgreSQL via Supabase (Supabase Auth + Supabase Storage) + Prisma ORM
- **AI Engine**: Google Gemini API via AI Adapter (`gemini-3.8-flash`)

## Project Structure
- `client/` : Aplikasi frontend React (JavaScript / JSX)
- `server/` : Backend Express.js (JavaScript) dengan Safety & Validation Engine, AI Adapter, dan Prisma
